1、请求头 referer ，当通过浏览器访问一个新页面时，浏览器的 referer 会自动记录跳转前的地址。若网站有反爬机制则需要模拟这方面的行为。

2、user-agent ，这个是浏览器记录访问的设备信息，通常服务器访问不会使用，需要设定一些虚假值模拟

3、访问间隔，一般大型网站会对同一个 ip 的连续访问时间进行检测，可通过增加每次访问间隔或使用变换代理 ip 解决

4、请求负载 atf|btf ，有的页面会使用 atf|btf 预加载，即一页之中也分为上下页，机器访问一般都是一整页访问，而人类需要往下看才会有下半页。

5、cookie 组，有的网页会在访问时设置 cookie ，正常的浏览行为不断跳转会一直积累 cookie 的长度，人为模拟记录即可

6、业务接口记录，这个就因网站而异了，一般大型网站都有埋点，机器行为需根据实际网站情况模拟人类操作

7、验证码（这种的话建议直接自己去网站复制 cookie 或 token 之类的跳过，程序模拟比较麻烦而且一般收费）
